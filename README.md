## Sobre

Um relógio grande, limpo e sem distrações: só as horas, minutos e segundos (`HH:MM:SS`), com o
tamanho se ajustando à largura da tela. Ideal para deixar aberto num monitor secundário, numa TV
ou num tablet.

## Rodando Localmente

Projeto estático, sem dependências: basta abrir o `index.html` no navegador.
